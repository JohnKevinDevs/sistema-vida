# Roadmap curto

## Atual

- Fase 6.0 concluida: revisao completa e debug geral do Sistema JK.

## Proximas fases sugeridas

### Fase 6.1 - Uso real controlado

- Usar o sistema com dados reais por um ciclo curto.
- Registrar bugs, friccoes e ajustes pequenos observados no uso.
- Corrigir apenas problemas reais antes de criar novas features.

### Fases futuras

- Metas persistentes.
- Revisoes diarias e semanais.
- Rotina e estudos persistentes.
- Memoria do Sistema JK.
- Embeddings e memoria vetorial.
- Busca semantica.
- Backup e exportacao.

## Principio do roadmap

Cada fase deve ser pequena, validavel e sem criar complexidade antes da hora.
