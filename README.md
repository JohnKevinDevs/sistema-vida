# Sistema JK

Sistema JK v1.0 - Vida e Tarefas.

## Objetivo

MVP local do segundo cerebro pessoal de John Kevin. Nesta fase, o projeto contem a base visual do modulo Vida e Tarefas com secoes organizadas, tipos reutilizaveis, estado local leve e polimentos basicos de UX/acessibilidade.

## Stack

- Next.js 14
- TypeScript
- App Router
- Tailwind CSS
- ESLint

## Instalar dependencias

```bash
npm install
```

## Rodar localmente

```bash
npm run dev
```

Depois, abra `http://localhost:3000`.

## Variaveis de ambiente

Crie ou mantenha um arquivo `.env.local` com as variaveis locais. Esse arquivo nao deve ser commitado.

Use `.env.example` como referencia.
