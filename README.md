# Sistema JK

Sistema JK v1 - Vida e Tarefas.

## Objetivo

MVP local do segundo cerebro pessoal de John Kevin. Nesta fase, o projeto contem apenas o setup inicial da aplicacao web.

## Stack

- Next.js 14
- TypeScript
- App Router
- Tailwind CSS
- ESLint

## Instalar dependencias

```bash
npm install
```

## Rodar localmente

```bash
npm run dev
```

Depois, abra `http://localhost:3000`.

## Variaveis de ambiente

Crie ou mantenha um arquivo `.env.local` com as variaveis locais. Esse arquivo nao deve ser commitado.

Use `.env.example` como referencia.
